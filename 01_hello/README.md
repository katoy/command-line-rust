## ファイル一覧

このプロジェクトには以下の主要なファイルが含まれています。

- `src/main.rs`: `hello` コマンドのメインソースコード。
- `tests/cli.rs`: コマンドラインツールの動作を確認する統合テスト。`assert_cmd` クレートを使用しています。

## テスト

ユニットテストおよび統合テストを実行するには、以下のコマンドを使用します。

```bash
cargo test
```

`tests/cli.rs` では、バイナリとしてビルドされたコマンドを実行し、その終了コードや標準出力を検証しています。

## Lint

コードの静的解析 (チェック) やフォーマットの確認を行うには、以下のコマンドを使用します。

### コードチェック
```bash
cargo check
```

### フォーマット確認
```bash
cargo fmt -- --check
```

## カバレッジレポート

コードカバレッジを測定するには `cargo-llvm-cov` の使用を推奨します。

### インストール (未インストールの場合)
```bash
cargo install cargo-llvm-cov
```

### レポート生成
コンソールにカバレッジサマリーを表示する場合:
```bash
cargo llvm-cov
```

テスト実行ログを省略し、サマリーテーブルのみを表示する場合:
```bash
cargo llvm-cov --summary-only
```


HTML 形式の詳細なレポートを生成する場合:
```bash
cargo llvm-cov --html
open target/llvm-cov/html/index.html
```
