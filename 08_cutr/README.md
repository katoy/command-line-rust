# cutr

`cutr` は、Unix の `cut` コマンドの Rust 版実装です。ファイルや標準入力から、指定したフィールド、バイト、または文字を抽出するコマンドラインツールです。

## 概要

`cutr` は、テキストデータから特定の部分を切り出すためのコマンドラインユーティリティです。オリジナルの `cut` コマンドと同様に、フィールド、バイト、文字単位での抽出をサポートし、さまざまなデリミタに対応しています。

## インストール

`cutr` をビルドするには Rust が必要です。

```bash
cargo install --path .
```

## 使用方法

### フィールド抽出

CSV や TSV のような区切り文字で区切られたファイルから特定のフィールドを抽出します。

```bash
cutr -f 1,3 input.csv
```

### バイト抽出

ファイルから特定のバイト範囲を抽出します。

```bash
cutr -b 1-5 input.txt
```

### 文字抽出

UTF-8 文字列から特定の文字を抽出します。

```bash
cutr -c 1-2,4 input.txt
```

### デリミタの指定

`-d` オプションでデリミタを指定できます。デフォルトはタブ文字です。

```bash
cutr -f 2 -d ',' input.csv
```

## 開発

### セットアップ

リポジトリをクローンします。

```bash
git clone https://github.com/your-username/cutr.git
cd cutr
```

### テスト

ユニットテストと結合テストを実行します。

```bash
cargo test
```

### Lint (`clippy`)

コードの品質と慣用性をチェックします。

```bash
cargo clippy
```

### カバレッジ計測

コードカバレッジを計測します。現在のカバレッジは 99.72% です。標準入力（`io::stdin()`）を扱うコードパスは、テスト環境でのモックが困難なため、カバレッジ計測から除外されていませんが、意図的に未カバーとしています。

```bash
cargo llvm-cov --summary-only
```
