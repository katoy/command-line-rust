## 機能

- 先頭からの行数指定出力 (`-n`, `--lines`)
- 先頭からのバイト数指定出力 (`-c`, `--bytes`)
- 複数ファイルの処理
- 標準入力のサポート

## 使用方法

```bash
# ビルドして実行
cargo run -- [オプション] [ファイル...]

# 例: ファイルの先頭 10 行を表示 (デフォルト)
cargo run -- filename.txt

# 例: 先頭 5 行を表示
cargo run -- -n 5 filename.txt

# 例: 先頭 20 バイトを表示
cargo run -- -c 20 filename.txt
```

## UTF-8 の扱い

本実装では、バイナリとしてファイルを読み込んだ後、`String::from_utf8_lossy` を使用して文字列に変換して出力します。
そのため、マルチバイト文字（UTF-8）の途中でバイト数が制限された場合（`-c` オプション使用時など）、不正なバイトシーケンスは Unicode 置換文字 () に置き換えられます。プログラムがパニックすることはありません。

**例:**
`α` (2バイト) + `あ` (3バイト) というファイルの場合:

- `-c 1` (1バイト目のみ): `` (α の前半のみ読み込まれるため置換)
- `-c 3` (3バイト目まで): `α` (あ の1バイト目のみ読み込まれるため置換)

## ファイル構成

プロジェクトの主要なファイル構成は以下の通りです。

```
.
├── Cargo.toml      # プロジェクト設定と依存関係
├── src
│   └── main.rs     # メインのアプリケーションロジック
└── tests
    ├── cli.rs      #統合テスト (コマンドライン引数のテスト)
    ├── inputs      # テスト入力用ファイル
    └── expected    # テストの期待される出力結果
```

## 開発

### Lint (静的解析)

コードの品質を保つために `cargo clippy` を使用しています。

```bash
cargo clippy
```

より厳格なチェックを行う場合は以下を実行します（推奨）:

```bash
cargo clippy -- -W clippy::pedantic
```

### テストとカバレッジ

本プロジェクトには、コマンドラインインターフェースの動作を確認する広範な結合テストが含まれています。

**テストの実行:**

```bash
cargo test
```

カバレッジレポートの生成には `cargo-tarpaulin` などのツールが使用できます (別途インストールが必要):

```bash
# インストール
cargo install cargo-tarpaulin

# カバレッジ計測
cargo tarpaulin --ignore-tests
```
