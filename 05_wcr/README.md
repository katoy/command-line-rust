# Rust版 wc (wcr)

Rust で実装された `wc` コマンド (wcr) です。
コマンドライン引数で指定されたファイル（または標準入力）の行数、単語数、バイト数、文字数をカウントします。

書籍 "Command-Line Rust" (O'Reilly) の第5章の実習コードです。

## 機能

- ファイルまたは標準入力からの読み込み
- 行数 (`-l`, `--lines`), 単語数 (`-w`, `--words`), バイト数 (`-c`, `--bytes`), 文字数 (`-m`, `--chars`) のカウント
- 複数のフラグの同時指定
- 複数ファイルの処理と合計の表示

## ファイル構成

```text
.
├── Cargo.lock
├── Cargo.toml      # 依存関係とプロジェクト設定
├── mk-outs.sh      # テスト用の期待値を生成するスクリプト
├── src
│   └── main.rs     # メインのソースコード
└── tests
    ├── cli.rs      # 統合テスト
    ├── expected    # テストの期待値ファイル群
    └── inputs      # テストの入力ファイル群
```

## 開発

### Lint (静的解析)

コードの品質チェックには `cargo clippy` を使用します。警告が出ないことを確認してください。

```bash
cargo clippy
```

### テスト

ユニットテストと統合テストを実行します。警告なしでパスすることを確認済みです。

```bash
cargo test
```

### カバレッジ

`cargo-llvm-cov` を使用して、コードカバレッジを計測します。
目標は **100%** です。

1. **ツールのインストール** (未インストールの場合):
   ```bash
   cargo install cargo-llvm-cov
   ```

2. **カバレッジの計測**:
   ```bash
   cargo llvm-cov --text
   ```

   HTMLレポートを生成してブラウザで確認する場合:
   ```bash
   cargo llvm-cov --html --open
   ```
