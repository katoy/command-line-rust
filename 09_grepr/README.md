## 機能

この `grepr` は、本家の `grep` コマンドに似た以下の機能をサポートしています。

-   **正規表現のサポート**: 検索パターンとして正規表現を使用できます。
-   **大文字・小文字を区別しない検索**: `-i` または `--ignore-case` オプションを使用して、大文字・小文字を区別せずに検索できます。
-   **カウントのみ**: `-c` または `--count` オプションを使用して、一致した行数のみを表示できます。
-   **逆検索**: `-v` または `--invert-match` オプションを使用して、パターンに一致しない行を表示できます。
-   **再帰的検索**: `-r` または `--recursive` オプションを使用して、ディレクトリを再帰的に検索できます。
-   **標準入力からの読み込み**: ファイルパスが指定されていない場合、標準入力から読み込みます。
-   **ファイル名の表示**: 複数のファイルを検索する際に、各一致行の前にファイル名を表示します。単一のファイルを検索する場合は表示しません。

## ビルド方法

```bash
cargo build --release
```

## 使い方

基本的な使い方は以下の通りです。

```bash
./target/release/grepr [OPTIONS] <PATTERN> [FILE...]
```

**例:**

-   `foo.txt` 内で "hello" を検索:
    ```bash
    ./target/release/grepr hello foo.txt
    ```
-   大文字・小文字を区別せずに "world" を検索:
    ```bash
    ./target/release/grepr -i world bar.txt
    ```
-   `src` ディレクトリ内で "fn" を再帰的に検索し、行数をカウント:
    ```bash
    ./target/release/grepr -rc fn src/
    ```

## 開発

このプロジェクトへの貢献を歓迎します。

### 警告の解消

このプロジェクトは現在、`cargo clippy` による警告や、非推奨APIの使用に関する警告がすべて解消されています。

### テスト期待値の生成 (`mk-outs.sh`)

`tests/expected` ディレクトリには、`grep` コマンドの実行結果の期待値が保存されています。
これらの期待値は `mk-outs.sh` スクリプトを使用して生成されます。
テストの挙動を変更した場合や、新しいテストケースを追加した場合は、このスクリプトを実行して期待値を更新してください。

```bash
./mk-outs.sh
```

### プラットフォーム依存の挙動

一部のテストおよび機能は、実行されるオペレーティングシステムに依存する挙動を示す場合があります。
特に、ファイルパーミッションの操作（Unix系OSのみ）や、改行コードの扱いはOSによって異なる可能性があります。
テストは主要なプラットフォーム（Linux, macOS, Windows）で動作するように設計されていますが、出力の差異が生じる可能性があります。
